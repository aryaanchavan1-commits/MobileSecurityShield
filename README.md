# MobileSecurityShield

Android app prototype for an AI-powered mobile security app with:
- login and device registration flows
- dashboard for threat status
- app and network scan screens
- multilingual UI in English, Hindi, and Marathi
- license plans for 3, 6, and 12 months
- Groq and Sarvam AI settings placeholders
- security-focused Android UX

## Important note
This is a UI and architecture prototype. Real mobile antivirus features that inspect all app activity, SMS, network traffic, or other apps at the OS level are limited by Android platform restrictions. This project demonstrates a realistic security app experience and backend integration design without claiming unauthorized system-wide surveillance.

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Android SDK 34

## Setup
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an Android emulator or device.

## Build notes
- Minimum SDK: 26
- Target SDK: 34

## Features included
- Secure login screen
- Threat dashboard
- App and network scan flow
- Subscription/license cards
- Settings for Groq API and Sarvam AI keys
- English/Hindi/Marathi language support
- Voice command examples for assistant actions
